# Algoritmos e Lógica de Programação

Repositório destinado aos estudos e exercícios desenvolvidos durante o curso de Algoritmos e Lógica de Programação, com foco na transição de pseudocódigo (VisuAlg) para uma linguagem de programação real (Java).

O objetivo deste projeto é consolidar os fundamentos da programação por meio da resolução de problemas, desenvolvimento do raciocínio lógico e aplicação dos principais conceitos de programação em Java — linguagem que escolhi como foco de carreira.

## Conteúdo

- Estruturas Sequenciais
- Estruturas Condicionais
- Estruturas Repetitivas
- Vetores
- Matrizes

## Linguagens

Este repositório foca deliberadamente em **VisuAlg** e **Java**:

- **VisuAlg** — usado para praticar lógica pura, sem a preocupação com sintaxe de uma linguagem real. É a base de todo exercício antes da tradução.
- **Java** — linguagem escolhida para aplicar os conceitos aprendidos, já que é o foco da minha trilha de carreira em desenvolvimento de software.

> O curso original também aborda C, C++, C# e Python. Optei por não replicar os exercícios nessas linguagens aqui, priorizando profundidade em Java em vez de cobertura superficial em várias linguagens. Essa foi uma escolha estratégica, não uma etapa incompleta.

## Objetivo

- Desenvolver raciocínio lógico;
- Aprimorar a capacidade de resolução de problemas;
- Consolidar fundamentos de programação aplicados a Java;
- Registrar a evolução dos estudos ao longo do tempo;
- Praticar a tradução de lógica (VisuAlg) para código real (Java).

## Estrutura do repositório

```

├── Java/        # Traduções e implementações em Java dos mesmos exercícios
```
