# Algoritmos e Lógica de Programação

Repositório destinado aos meus estudos de Algoritmos e Lógica de Programação.

Os exercícios são desenvolvidos durante cursos e estudos práticos, com foco na construção de uma base sólida em programação e resolução de problemas.

## Conteúdo

- Estruturas Sequenciais
- Estruturas Condicionais
- Estruturas Repetitivas
- Vetores
- Matrizes

## Tecnologias e Linguagens

- VisualG
- C
- C++
- C#
- Java
- Python

## Objetivo

Desenvolver raciocínio lógico, capacidade de resolução de problemas e fundamentos de programação, servindo como base para estudos mais avançados em desenvolvimento de software.
